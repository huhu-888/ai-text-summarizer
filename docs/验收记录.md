# 验收记录

## 一、正常文本

**输入：**

```json
{
  "text": "哎我跟你说啊，就是昨天吧，我本来想着下班早点回家休息的，结果呢，我们那个领导突然在群里发消息说，哎大家先别走啊，有个紧急的项目要赶一下，然后我们一群人就被留下来加班了。加到大概晚上九点多吧，我饿得不行了，就点了份外卖，结果外卖还送错了，送成隔壁公司的了，等找回来都凉透了。然后好不容易弄完，我打车回家，路上又堵车堵了快一个小时，到家都快十一点了。"
}
```

**结果：**

```json
{
  "summary": "昨天我本想早回家，却临时加班到九点多，外卖送错凉透，打车又堵近一小时，到家近十一点。"
}
```

**状态码：** 200 ✅

## 五、调用失败

### Key 错误

**操作：** `.env` 改成假 Key

**结果：** 模型调用失败，返回 500 ✅

### 余额不足

**操作：** 账户余额为 0

**结果：** `Error code: 402 - Insufficient Balance`，返回 500 ✅

---

## 六、改需求：新增 max_length 参数

**需求：** 加一个 `max_length` 参数，控制摘要长度。

**改动：**

- `llm_service.py`：`summarize` 函数加 `max_length` 参数，system 里用 `f"...不超过 {max_length} 字..."`
- `api.py`：`SummarizeRequest` 加 `max_length` 字段，调用时传入

**测试 1（默认 50 字）：**

```json
{"text": "..."}
```

结果：

```json
{"summary": "昨天我本想早回家，却临时加班到九点多，外卖送错凉透，打车又堵近一小时，到家近十一点。"}
```

**测试 2（指定 20 字）：**

```json
{"text": "...", "max_length": 20}
```

结果：

```json
{"summary": "昨天加班后外卖送错，打车又堵车晚归。"}
```

**对比：**

| 测试 | max_length | 摘要长度 |
|------|------------|----------|
| 1 | 50（默认） | 约 40 字 |
| 2 | 20 | 约 18 字 |

**结论：** `max_length` 参数生效 ✅

## 七、排错过程

### 问题 1：`/docs` 页面白屏

**现象：** 浏览器打开 `/docs`，页面空白。

**原因：** Swagger UI 依赖 CDN 上的 JS/CSS，国内加载失败。

**解决：** 用 `/redoc` 代替，或者用 curl/Python 测试接口。

### 问题 2：Key 错误但不报错

**现象：** 改了假 Key，运行没报错。

**原因：** `input.txt` 是空的，代码在“空文本”那一步就返回了，没走到调模型。

**解决：** 往 `input.txt` 写内容，再运行，才触发调模型，报 401。
